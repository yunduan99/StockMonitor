gp 股票行情悬浮工具
====================

一、如何启动
------------
1. 打开本文件所在文件夹。
2. 双击 StockMonitor_final.exe。
3. 程序启动后会在屏幕右上角显示行情悬浮窗，并在任务栏通知区域显示图标。
4. 不需要安装 Python 或其他运行环境。

二、如何关闭和显示/隐藏
------------------------
- 按 Alt+Z：在“显示”和“隐藏”之间切换悬浮窗。
- 按 Alt+X：退出程序。
- 也可以右键点击任务栏通知区域的 gp 图标，选择“显示 / 隐藏”或“退出”。

三、如何移动和调整大小
----------------------
- 在悬浮窗文字或空白处按住鼠标左键并拖动，可以移动窗口。
- 将鼠标移到窗口顶部或底部边缘，出现上下缩放光标后按住左键拖动，可以调整高度。
- 窗口启动时默认显示一行数据；高度调整后会按照完整行数显示，不会显示半行。

四、如何滚动查看更多股票
------------------------
- 自选股超过当前显示行数时，将鼠标放在悬浮窗内滚动鼠标滚轮。
- 每次滚轮操作向上或向下移动一整行，不会停在半行位置。
- 先单击悬浮窗，再按键盘上方向键或下方向键，也可以逐行滚动。

五、如何修改股票和界面配置
--------------------------
1. 先退出程序。
2. 用记事本打开同目录的 stock_list.json。
3. 每只股票填写：
   code       市场前缀加六位代码，例如 sh600519 或 sz000001
   alias      显示名称
   cost_price 持仓成本价
   shares     持仓股数（整数，缺省为 0）
4. 如需修改刷新时间、颜色、字体、置顶或快捷键，编辑同目录的 config.json。
5. 保存文件后重新启动程序。

常用 config.json 设置：
  "refresh_interval": 10
  "always_on_top": true
  "minimize_hotkey": "alt+z"
  "close_hotkey": "alt+x"
  "query_time_ranges": ["09:15-11:30", "14:30-15:00"]

程序在规定时间外首次启动时仍会查询一次，之后只在 query_time_ranges 指定时段内
按刷新间隔查询。时间格式必须为 HH:MM-HH:MM。

六、行情显示含义
----------------
名称 | 当前价 | 当日涨跌幅 | 持仓盈亏比例 | 今日涨跌金额
当日涨跌幅 = (当前价 - 昨日收盘价) / 昨日收盘价
持仓盈亏比例 = (当前价 - 成本价) / 成本价
今日涨跌金额 = (当前价 - 昨日收盘价) × 持仓股数，显示带正负号的整数金额。
最后一行 total 为汇总：依次显示总盈亏金额（百元）、持仓总涨跌百分比、当日总涨跌百分比、
当日总盈亏金额（百元）。金额按四舍五入显示为整数，百分比按总成本和总昨日市值加权计算。
无法获取数据时显示 --，程序会在下一轮自动重试。

七、日志和故障排查
------------------
程序会在同目录生成 gp_debug_YYYY-MM-DD.log，每天一个文件，仅保留最近三天。
启动时会自动删除三天以前的日志和旧版 gp_debug.log。
如行情为空或快捷键无反应，请把当天的日志文件发给维护人员。

八、用户标识
------------
每个 Windows 用户首次启动时，程序会在该用户的 %APPDATA%\gp\rid.json 生成唯一标识，
并后台上报一次。以后启动不会重复生成或重复上报。上报失败不会影响程序使用。

九、注意事项
------------
- Windows 任务栏是否把 gp 图标放入“角溢出”由系统设置决定。
- 全屏云桌面通常支持置顶显示；如果云桌面使用系统级安全覆盖层，可能禁止普通程序覆盖。
- 修改 JSON 时请保留双引号、逗号和中括号/大括号，格式错误时程序会使用安全默认值运行。
